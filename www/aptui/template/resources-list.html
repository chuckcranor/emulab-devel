This information is intended to help you determine who in your project has active reservations for node types that are being used in your project. Since reservations are per-project (anyone in your project can use the nodes), you will sometimes get into a situation where you have nodes reserved, but another member of the project is using them, and thus you are not able to start your experiments. This table can help you figure out who in your project to contact.
By User: Total number of nodes of this type, reserved by the user who started this experiment (active reservations, not future reservations). Zero means the user does not have any active reservations for the node type.
By Project: Total number of nodes of this type, reserved by the project (active reservations, not future reservations). This includes all reservations by all users in the project. Zero means there are no active reservations in the project for nodes of this type.
Numbers (in this color) in the Using column indicate a user that has allocated more nodes than they have reserved (but only if other users in the project have reservations for them).
