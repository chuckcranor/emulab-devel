#
# List of third-party app ports that often show up in CloudLab experiments.
# Intended for running NMAP scans on nodes for a quick check of potentially
# exposed and vulnerable ports. Includes:
#
#  * Apache stuff: Hadoop (HDFS, MapReduce, YARN), Spark, ZooKeeper
#  * Docker
#  * ELK stack (Elasticsearch, Logstash, Kibana)
#  * VNC
#
# XXX need to add UDP ports where appropriate, though scanning those
# is slow.
#
# There are of course many other ports for many other apps.
#
# Updated 04/22/2022
