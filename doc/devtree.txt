Setting up a dev tree, approximate instructions.

0. Prepare.
   You should have shell-on-boss, be in the tbadmin group, have an emulab-devel
   tree (master branch) checked out, and be logged in to boss.emulab.net.

   You should do all of the following as yourself, and NOT as root unless there
   is an explicit "sudo" in the instructions below.

1. Make the base directories.

   user=<your-admin-user-name>

   mkdir -p /usr/testbed/devel/$user
   mkdir -p /usr/testbed/opsdir/devel/$user
   cd /usr/testbed/www/dev
   ln -s ../../devel/$user $user
   cd /usr/testbed/www/apt/dev
   ln -s ../../../devel/$user/www/apt $user

2. Create a defs file

   srcdir=<your-checked-out-emulab-devel-repo>
   cd $srcdir
   cp defs-mike-emulab defs-$user-emulab
   <edit and change defs-$user-emulab in the obvious way>

3. Build, and install the source.
   The "--prefix=" is very important here so you won't be installing in
   the main tree!

   mkdir ~/obj/testbed-dev
   cd ~/obj/testbed-dev
   $srcdir/configure --prefix=/usr/testbed/devel/$user \
       --with-TBDEFS=$srcdir/defs-$user-emulab
   gmake
   gmake boss-install

4. Symlinks

   mv /usr/testbed/devel/$user/opsdir/* /usr/testbed/opsdir/devel/$user/
   ln -sFn /usr/testbed/opsdir/devel/$user opsdir

5. Apache config files changes.

5a. httpd-geni.conf needs:

ScriptAlias /protogeni/$user/xmlrpc /usr/testbed/devel/$user/protogeni/xmlrpc/protogeni-wrapper.pl

<Directory "/usr/testbed/devel/$user/protogeni/">
        SSLRequireSSL
        Order deny,allow
        deny from all
        allow from 155.98.60.
        allow from 155.98.63.
        allow from 155.98.32.
        allow from 155.98.33.74

	<add user-specific IP addresses>

        SSLOptions +StdEnvVars +ExportCertData +LegacyDNStringFormat
        Options +ExecCGI +FollowSymLinks
        SetHandler cgi-script
        SetEnv USER "nobody"
</Directory>

5b.. httpd-www.conf needs:
   
<Directory "/usr/testbed/devel/$user/protogeni/">

5c. Restart apache

   sudo /usr/local/etc/rc.d/apache24 reload

6. Other stuff to incorporate:

   - Either symlink /usr/testbed/opsdir/lib/geni-lib into the devtree
     or clone your own copy into /usr/testbed/devel/$user/opsdir/lib/geni-lib.

   - Modify apt/APT_Instance.pm.in to fix up $usemydevtree code appropriately.
     This would be better handled with a configure var like USE_DEVTREE=<user>
